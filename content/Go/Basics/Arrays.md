# Go 基础：数组

数组是固定长度的同类型元素序列。长度是数组类型的一部分，因此 `[3]int` 和 `[5]int` 是两种不同的类型。

在实际 Go 代码中，切片比数组更常见；数组更多出现在需要固定大小、可比较或值语义的场景。理解数组是理解切片的基础。

[Go by Example 的 Arrays](https://gobyexample.com/arrays) 展示了声明、初始化、索引和二维数组。本文补充值语义、比较和数组与切片的区别。

## 完整示例

```go
package main

import "fmt"

func main() {
	var a [5]int
	fmt.Println("emp:", a)

	a[4] = 100
	fmt.Println("set:", a)
	fmt.Println("get:", a[4])

	fmt.Println("len:", len(a))

	b := [5]int{1, 2, 3, 4, 5}
	fmt.Println("dcl:", b)

	b = [...]int{1, 2, 3, 4, 5}
	fmt.Println("dcl:", b)

	b = [...]int{100, 3: 400, 500}
	fmt.Println("idx:", b)

	var twoD [2][3]int
	for i := range 2 {
		for j := range 3 {
			twoD[i][j] = i + j
		}
	}
	fmt.Println("2d: ", twoD)

	twoD = [2][3]int{
		{1, 2, 3},
		{1, 2, 3},
	}
	fmt.Println("2d: ", twoD)
}
```

运行：

```bash
$ go run arrays.go
emp: [0 0 0 0 0]
set: [0 0 0 0 100]
get: 100
len: 5
dcl: [1 2 3 4 5]
dcl: [1 2 3 4 5]
idx: [100 0 0 400 500]
2d:  [[0 1 2] [1 2 3]]
2d:  [[1 2 3] [1 2 3]]
```

## 声明与零值

```go
var a [5]int
fmt.Println(a) // [0 0 0 0 0]
```

`[5]int` 表示“长度为 5 的 int 数组”。声明后，数组的每个元素都会被初始化为对应类型的零值；对 `int` 来说就是 `0`。

数组的长度必须是非负常量：

```go
const n = 5
var a [n]int // 合法

m := 5
var b [m]int
// invalid array length m
```

长度是类型的一部分，所以下面两个变量类型不同，不能直接赋值：

```go
var a [3]int
var b [5]int
// a = b // cannot use b (variable of type [5]int) as [3]int value
```

## 索引与长度

数组下标从 `0` 开始，最大下标是 `len(a)-1`：

```go
a[0] = 1
a[4] = 100

fmt.Println(a[0]) // 1
fmt.Println(a[4]) // 100
fmt.Println(len(a)) // 5
```

越界访问会编译失败（下标是常量时）或运行时 panic（下标来自变量时）：

```go
var a [3]int
a[3] = 1
// invalid argument: index 3 out of bounds [0:3]
```

`len` 返回数组长度。数组的容量 `cap` 与长度相同，但日常几乎不需要对数组使用 `cap`。

## 数组字面量

可以在声明时直接初始化：

```go
b := [5]int{1, 2, 3, 4, 5}
```

元素个数少于长度时，剩余元素自动补零：

```go
c := [5]int{1, 2}
fmt.Println(c) // [1 2 0 0 0]
```

元素个数多于长度会编译失败。

用 `...` 让编译器根据元素个数推断长度：

```go
b := [...]int{1, 2, 3, 4, 5}
fmt.Println(len(b)) // 5
```

`[...]` 只能用在数组字面量中，不能用于变量声明或函数参数类型。

## 按索引初始化

可以在字面量中指定下标，未指定的位置补零：

```go
b := [...]int{100, 3: 400, 500}
fmt.Println(b) // [100 0 0 400 500]
```

这里的含义是：

- 下标 `0` 赋值为 `100`；
- 下标 `3` 赋值为 `400`；
- 下标 `4` 赋值为 `500`；
- 下标 `1`、`2` 保持零值。

编译器根据最大下标推断数组长度为 5。

## 多维数组

数组可以嵌套，形成多维数组：

```go
var twoD [2][3]int
for i := range 2 {
	for j := range 3 {
		twoD[i][j] = i + j
	}
}
fmt.Println(twoD) // [[0 1 2] [1 2 3]]
```

`[2][3]int` 是一个长度为 2 的数组，每个元素是 `[3]int`。它在内存中是连续的矩形结构，不是“数组的数组”那种可以长度不一的锯齿结构。

也可以在声明时初始化：

```go
twoD := [2][3]int{
	{1, 2, 3},
	{1, 2, 3},
}
```

内层复合字面量的类型可以省略，但元素数量仍要匹配。

## 数组是值类型

这是数组和切片最重要的区别之一：**数组赋值会复制整个数组**。

```go
a := [3]int{1, 2, 3}
b := a
b[0] = 99

fmt.Println(a) // [1 2 3]
fmt.Println(b) // [99 2 3]
```

把数组传给函数同样会复制：

```go
func modify(a [3]int) {
	a[0] = 99
}

func main() {
	a := [3]int{1, 2, 3}
	modify(a)
	fmt.Println(a) // [1 2 3]
}
```

如果希望在函数内修改原数组，可以传指针：

```go
func modify(a *[3]int) {
	a[0] = 99
}
```

不过在实际项目中，需要动态长度或共享底层数据时，通常直接使用切片。

## 数组比较

如果元素类型可比较，数组可以用 `==` 和 `!=` 比较：

```go
fmt.Println([3]int{1, 2, 3} == [3]int{1, 2, 3}) // true
fmt.Println([3]int{1, 2, 3} == [3]int{1, 2, 4}) // false
```

比较要求两个数组类型完全相同，包括长度。元素类型不可比较时（例如元素是切片），数组也不能比较：

```go
var a [2][]int
// a == a // invalid operation: [2][]int cannot be compared
```

## 用 `range` 遍历数组

```go
a := [3]int{10, 20, 30}
for i, v := range a {
	fmt.Println(i, v)
}
```

输出：

```text
0 10
1 20
2 30
```

`v` 是元素的副本，修改 `v` 不会修改数组。要修改元素，使用下标：

```go
for i := range a {
	a[i] *= 2
}
```

## 数组 vs 切片

| 对比项 | 数组 | 切片 |
| --- | --- | --- |
| 长度 | 类型的一部分，固定 | 运行时可变 |
| 类型 | `[N]T` | `[]T` |
| 赋值 | 复制整个数组 | 复制切片头，共享底层数组 |
| 比较 | 元素可比较时可用 `==` | 只能和 `nil` 比较 |
| 扩容 | 不支持 | `append` 自动扩容 |
| 常见程度 | 较少 | 非常常见 |

数组适合固定大小的数据，例如哈希值、固定缓冲区；大多数业务场景使用切片。

## 常见错误

### 1. 下标越界

数组下标范围是 `0` 到 `len(a)-1`。访问 `a[len(a)]` 会失败。

### 2. 使用变量作为数组长度

数组长度必须是常量。需要运行时决定长度时，使用切片。

### 3. 期待数组赋值共享数据

数组赋值是复制。两个数组变量各自拥有独立的数据。

### 4. 用 `append` 操作数组

`append` 的参数必须是切片，不能直接对数组使用。需要先转换成切片：`a[:]`。

### 5. 比较元素不可比较的数组

数组的 `==` 要求元素类型可比较。包含切片、map、函数等元素的数组不能比较。

### 6. 字面量元素过多

`[3]int{1, 2, 3, 4}` 会编译失败。元素少于长度是允许的，剩余位置补零。

## 和 Java 对照

| 概念 | Go | Java |
| --- | --- | --- |
| 长度 | 类型的一部分 | 运行时属性 `length` |
| 赋值 | 复制整个数组 | 复制引用 |
| 比较 | `==` 比较元素（可比较时） | `==` 比较引用，内容用 `Arrays.equals` |
| 打印 | `fmt.Println` 直接显示元素 | 默认显示对象地址，需 `Arrays.toString` |
| 多维 | `[2][3]int` 矩形 | `int[][]` 数组的数组，可锯齿 |
| 动态长度 | 用切片 | 用 `ArrayList` 等集合 |

Java 的数组是引用类型，`int[] a = b` 只是复制引用；Go 的数组是值类型，赋值会复制整个数组。这个差异在把 Java 代码翻译成 Go 时尤其需要注意。

## 小结

- 数组长度固定，且长度是类型的一部分。
- 数组声明后元素自动取零值。
- 支持 `[...]` 推断长度和按索引初始化。
- 多维数组是矩形结构，不是锯齿数组。
- 数组是值类型，赋值和传参都会复制；切片则共享底层数组。
