# Go 学习笔记

这里记录我学习 Go 的完整路径。笔记以 [Go by Example](https://gobyexample.com/) 的示例为线索，但不只是翻译示例：每个知识点都会补充运行机制、常见错误，以及和 Java 等语言的对照。

## 学习路线

- **基础**：包、变量、函数、流程控制、集合、错误处理
- **进阶**：结构体、接口、泛型、反射
- **并发**：goroutine、channel、`select`、同步原语、并发模式
- **工程化**：模块、测试、基准测试、性能分析、部署
